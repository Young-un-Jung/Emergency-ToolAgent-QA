팀: 양태훈 · 정영운 · 배효림

## 시나리오: 사용자 맞춤 응급실 추천

사용자의 위치, 증상, 이동 수단을 슬롯 질문으로 받은 뒤 응급의료기관 API를 호출해 응급센터 등급, 진료 가능 분야, 병상 여유, 거리를 조회하고 가장 적합한 응급실을 답하는 Tool Agent 대화를 QA 데이터로 구성했습니다.

```
USER   배가 너무 아픈데 응급실 어디 가야 해?
AGENT  (슬롯 질문) 현재 위치(구 단위), 증상, 119 이용 여부
USER   미추홀구 / 복통 / 택시 탈 예정
AGENT  (Tool Call) 지역 응급의료기관 실시간 조회: 등급, 진료 분야, 병상, 거리
AGENT  가장 적합한 응급실은 OO병원입니다. 2.1km 거리이며 복통 진료가 가능하고 병상 3개가 남아 있습니다.
```

API: [공공데이터포털 응급의료기관 정보](https://www.data.go.kr/data/15000563/openapi.do)
